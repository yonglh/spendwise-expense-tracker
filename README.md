# SpendWise Expense Tracker

SpendWise is a React mini project for tracking personal expenses. It lets users view spending summaries, add new expenses, browse their expense history, and delete old records.

## Project Requirements Covered

- Built with Vite.
- Uses functional React components and hooks.
- Contains multiple components with props passed between them.
- Uses React Router for three client-side routes: dashboard, expenses, and add expense.
- Manages shared expense state with `useState`.
- Persists expense data with `localStorage`.
- Includes loading and error handling around persistence.
- Includes a controlled form to create new expenses.
- Displays a collection of expenses and supports deleting an expense.

## Run Locally

```bash
npm install
npm run dev
```
